# Limen for Homebrew

```sh
brew install alfonsocampodonico/limen/limen
```

Limen is a small compiled language where code can only touch the outside
world through capabilities it was handed. The book is at
https://book.limen-lang.org.

Builds are for macOS on Apple silicon. Programs compile through C, so the
Xcode Command Line Tools (`xcode-select --install`) must be installed.
